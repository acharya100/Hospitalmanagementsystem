Restaurant Management System

This project is a Django-based restaurant management system. It includes separate Django apps for menus, orders, reservations, restaurants, reviews and users.


What this project contains

'backend/' — Django project settings, main URLs, ASGI/WGSI files.
'departments/' — department items, serializers, views and department-related API logic.
'prescriptions/' — prescriptions models, serializers and prescription handling.
'appointments/' — hospital appointment functionality.
'hospitals/' — hospital data, open/close status and hospital APIs.
'reviews/' — customer reviews and review APIs.
'users/' — user profiles, authentication-related models and serializers.
env/ — local Python virtual environment used for dependencies.
